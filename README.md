# KaamSetu (कामसेतु) - Hyperlocal Blue-Collar Services Platform

> **Social Impact Mission:** Transforming blue-collar work from exploitative fixed-rate gig platforms into a dignified, worker-centric hyperlocal marketplace with live reverse bidding, voice-first regional accessibility, and multi-tier trust protection.

---

## 🌟 The Core Differentiators

Unlike Urban Company's monopolistic fixed pricing and 40-50% commission extraction, **KaamSetu** empowers technicians with:

1. **Mini Reverse Auction (Headline Feature):**
   - Customer posts a job (e.g., *"Leaking tap, target budget ₹300–₹500"*).
   - Nearby verified technicians receive pings and submit bids or counteroffers.
   - Dynamic **Fair-Price Guide** (e.g., *"Typical range for this job in Mumbai: ₹250–₹450"*) prevents price gouging or worker exploitation.
   - 3-Minute countdown keeps matching fast.

2. **The 30-Minute Hyperlocal Promise:**
   - Real-time interactive GPS map tracking 30+ verified Mumbai workers.
   - "Available Now" toggle for immediate dispatch vs scheduled booking.
   - **Auto-escalation engine**: If not matched within 3 minutes, the search radius automatically widens (3 km → 7.5 km) notifying more technicians.
   - Live **"Arrives in 18 min"** tracker with route line and status updates.

3. **Trust & Safety Stack (Zero-Thinness):**
   - **4-Tier Verification Badges:**
     - 🟢 Tier 1: Aadhaar / DigiLocker biometric e-KYC
     - 🟢 Tier 2: Mumbai Police Special Branch clearance certificate
     - 🟢 Tier 3: NSDC / Skill India trade evaluation
     - 🟢 Tier 4: Community Trust Score (90-100 scale)
   - **Photo-Verified Arrival & OTP Job Start:** 4-digit code prevents impersonation.
   - **Emergency SOS Siren & Location Dispatch:** Audible siren + instant alert to Mumbai Police 112 & emergency contact.
   - **Two-Way Protective Ratings:** Protects technicians against abusive or non-paying clients.
   - **Escrow-Lite:** Client payment is held safely and released ONLY after customer verifies satisfaction.
   - **Dispute Resolution:** Upload before/after photo evidence with 15-minute arbitration.

4. **Worker-First (Ustaad Mode) Accessibility:**
   - **Voice-First & Icon-Based UI** in English, Hindi (हिन्दी), and Marathi (मराठी).
   - **Voice Quotes:** Workers tap mic and speak: *"₹350 रुपया, 15 मिनिटात पोहोचतो"* — transcribed directly into a bid!
   - **2G SMS / WhatsApp Fallback:** Accessible on basic feature phones.
   - **Earnings Dashboard:** Daily/weekly take-home, 100% payout, instant UPI withdrawal.
   - **AI Skill Upskilling Nudges:** E.g., *"Add Inverter AC repair to earn +32% more in Bandra West"*.
   - **Live Demand Heatmap:** Hotspot clustering across Mumbai (Andheri, Bandra, Powai, Dadar).

5. **Smart Touches:**
   - **AI Problem Diagnostics:** Customer snaps a photo; AI diagnoses the issue and estimates fair pricing.
   - **Bundled Jobs:** Combo plumber + electrician visit (-15% discount).
   - **Recurring Bookings:** Daily/monthly maid and cook plans with **Zero-Disruption Auto-Substitute Guarantee**.

## 🛠️ Tech Stack

- **Frontend:** React 18, Vite 5, Tailwind CSS
- **Mapping:** Leaflet.js with custom DivIcons, GPS coordinates, route polyline
- **Audio Engine:** Web Audio API (Synthesized pings, fanfare, emergency SOS siren)
- **Icons & Visuals:** Lucide React, Unsplash high-res photography, custom SVG Brand Identity
